## 🚀 Build Command Reference

### Debug Build (Testing)
```bash
cd /mnt/c/Dev/Thorium-player
./scripts/build-debug-apk.sh
```
**Output**: `android/android/app/build/outputs/apk/debug/app-debug.apk`

### Release Build (Play Store)
```bash
# Step 1: Generate keystore (one-time)
./scripts/generate-keystore.sh

# Step 2: Set environment variables (shown by step 1)
export RELEASE_KEYSTORE="/path/to/keystore"
export RELEASE_KEYSTORE_PASSWORD="password"
export RELEASE_KEY_ALIAS="key-alias"
export RELEASE_KEY_PASSWORD="key-password"

# Step 3: Build
./scripts/build-release.sh
```
**Outputs**: 
- APK: `android/android/app/build/outputs/apk/release/app-release.apk`
- AAB: `android/android/app/build/outputs/bundle/release/app-release.aab`

### Direct Gradle Commands
```bash
cd /mnt/c/Dev/Thorium-player/android/android

# Debug
./gradlew assembleDebug

# Release
./gradlew assembleRelease

# Bundle (AAB for Play Store)
./gradlew bundleRelease

# Clean
./gradlew clean
```

## 🐛 Troubleshooting Quick Reference

| Issue | Solution |
|-------|----------|
| Build fails with gradle error | Run `cd android/android && ./gradlew clean` |
| APK not found | Check `android/android/app/build/outputs/` |
| Out of memory during build | Increase heap in `gradle.properties` |
| Permission denied on scripts | Run `chmod +x scripts/*.sh` |
| Release build fails | Verify environment variables are set |
| App crashes on startup | Check `adb logcat` for errors |
